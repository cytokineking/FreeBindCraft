# MetalJAX backend

The Apple installer downloads FreeBindCraft's optimized MetalJAX build automatically. Attention and conversion optimizations are enabled by default.

For installation and usage, see the [Apple Silicon guide](../../apple_silicon/README.md).

Backend source lives in the [MetalJAX fork](https://github.com/cytokineking/metaljax). Maintainers can build it with `installation/build_metaljax_apple.py`; normal installation uses the prebuilt package.
